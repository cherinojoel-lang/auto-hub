⚡ Bolt: [performance improvement] Optimize vehicle filtering with single iteration

💡 **What:** Replaced the 5 chained `.filter()` array iterations with a single `.filter()` call containing early returns. Also hoisted `parseInt()` and `.toLowerCase()` operations outside of the `.filter()` loop so they are calculated only once per filter application instead of once per element.

🎯 **Why:** The previous chained `.filter()` implementation required iterating over the vehicle array up to 5 times for a full filter condition, and re-calculating the `.toLowerCase()` or `parseInt()` comparisons for every single element, causing redundant CPU cycles and memory allocations.

📊 **Measured Improvement:**
Baseline (chained filters): ~5390ms for 50 iterations of 170,000 array items.
Improved (single iteration + hoisted calculations): ~4694ms for the same data.
This yields a ~13% direct speed improvement during execution of the search filter block.
