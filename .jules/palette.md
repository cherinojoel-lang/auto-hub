## 2024-05-27 - Conditionally Rendered Elements & ARIA Controls
**Learning:** When a target element (like a mobile navigation menu) is conditionally rendered (e.g. `mobileMenuOpen && <nav id="mobile-menu">`), statically assigning `aria-controls="mobile-menu"` to the toggle button creates an accessibility issue because the referenced ID doesn't exist in the DOM when the menu is closed. Screen readers may announce a broken reference.
**Action:** When working with conditionally mounted nodes, always conditionally apply the `aria-controls` attribute (e.g., `aria-controls={isOpen ? 'target-id' : undefined}`) to ensure it only references elements that are actually present in the DOM. Alternatively, use CSS to visually hide elements (like `hidden` vs `block`) rather than unmounting them, which allows for static `aria-controls` assignments.
