## 2024-03-24 - Stateful Toggle Button Accessibility Improvements
**Learning:** React toggle buttons (like mobile menus) often lack stateful accessibility attributes. Screen readers cannot announce the state (open/closed) if `aria-expanded` is missing. Additionally, when using `aria-controls` to link to a target container that only conditionally mounts in the DOM (e.g., `{isOpen && <div id="target" />}`), a static string will cause `aria-controls` to reference a non-existent node when closed, which is an accessibility error.
**Action:** When implementing a stateful toggle button, always include `aria-expanded={isOpen}`, localized/dynamic `aria-label`, and `focus-visible` styles. To fix the missing DOM node issue, dynamically set `aria-controls={isOpen ? 'target-id' : undefined}`.
