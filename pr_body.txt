💡 **What:** Replaced six chained `.filter()` calls with a single `.filter()` call containing logical `&&` operations in `src/lib/domain/vehicleFilter/filterVehicles.ts`.

🎯 **Why:** Chained filters iterate over the array multiple times, creating a new intermediate array at each step. This increases memory allocation overhead and wastes CPU cycles. Combining them into a single pass applies short-circuit evaluation efficiently and reduces array allocations to just one.

📊 **Impact:** The code is now ~1.37x faster.
- Iterations: Reduced from potentially 6x N to 1x N.
- Memory: Only one result array is allocated instead of up to 6 intermediate arrays.

🔬 **Measurement:**
Benchmarked locally using `vitest bench` with 50,000 generated vehicles.
- Baseline (Chained): ~8.92ms mean execution time
- Optimized (Single Pass): ~6.51ms mean execution time
- Improvement: ~1.37x speedup
